# septet LGMF 2026

A composition for english horn, bassoon, horn, trumpet, cello, double bass and percussion —
three pairs and a percussionist — written for the Lake George Music Festival 2026 call.
Piece #6 in the composer's custom-composition-system lineage; the software is ported from
`septet_2026` (piece #5, the Tempus septet), which was ported from `for_seven_tubas` (piece #4).

Orientation for any AI session: `CLAUDE.md`, then `docs/PROJECT_JOURNAL.md` §2.
